## 🎨 设计决策速览

### 风格方向

| 来源 | 采纳内容 |
|---|---|
| **UKUI**（主基调） | 底部任务栏 + 左下角启动器 + 中文优先信息层级 |
| **KDE Plasma** | 四级阴影高度分级、毛玻璃面板、窗口贴靠(Snap)、Alt+Tab 切换器 |
| **XFCE** | 轻量原则：少装饰、短促动效、不做坞式放大 |

### 设计令牌

- **主色**：UKUI 科技蓝 `#3790FA`（深色 `#4C9DFB`）
- **圆角**：4 / 6 / 8 / 12px，窗口固定 **10px**（最大化时归零）
- **阴影**：四级 E1–E4，激活窗口 E3、拖拽中 E4、极简档全部降级为 1px 描边
- **动效**：120ms 悬停 / 200ms 弹层 / 320ms 窗口几何动画，`prefers-reduced-motion` 时归零
- **字体**：Noto Sans CJK SC → Source Han Sans SC → PingFang SC → Microsoft YaHei
- **间距**：严格 4 的倍数（4/8/12/16/24/32）
- **对比度**：全部满足 WCAG AA（正文 ≥12:1，辅助文字 ≥4.6:1）

## ⚡ 低性能设备：三条硬约束

### 1. 性能分级（三档 + 自动检测）

| 档 | 背景 | 阴影 | 动效 | 触发 |
|---|---|---|---|---|
| **完整** | 毛玻璃 blur(22px) | 四级 E1–E4 | 320ms 几何动画 | 仅手动 |
| **均衡** | 静态半透明 | 静态阴影 | 200ms，无逐项动画 | 检测到硬件加速（自动默认） |
| **极简** | 纯色不透明 | 关闭，1px 描边替代 | 仅 120ms 淡入，无位移缩放 | 检测到 llvmpipe / SwiftShader / 无 WebGL（自动） |

检测方式：读取 `WEBGL_debug_renderer_info` 的 `UNMASKED_RENDERER`，命中 `llvmpipe|swiftshader|softpipe|software` 即判软渲染。落到 Qt 侧对应 `QSGRendererInterface::GraphicsApi` / `glGetString(GL_RENDERER)`。

**软渲染成本红线**：禁实时背景模糊、禁逐项 stagger 入场、禁 ≥3 层半透明叠加、禁滚动中实时光栅化 SVG 图标、列表必须虚拟化、搜索必须防抖 + 结果截断。

### 2. 开始菜单：紧凑单页（Whisker 演进）

固定 344×486（xs 档 292 / lg 档 400），**不支持 resize**，消除布局重排。

```
┌────────────────────────────┐
│ 搜索框（打开即聚焦，防抖 160ms，截断 20 条，支持中文/拼音/首字母）│ 34px
├──────┬─────────────────────┤
│ 分类 │ 应用单列列表          │
│ 76px │ 行高 40px / 图标 24px │
│ 全部 │ 悬停整行变色          │
│ 常用 │ ↑↓ 键盘选择 + Enter   │
│ 办公 │                     │
│ 开发 │                     │
│ 影音 │                     │
│ 系统 │                     │
├──────┴─────────────────────┤
│ 头像 kylin       锁屏  电源  │ 46px
└────────────────────────────┘
```

放弃大图标网格的原因：网格单元 96px + 文字换行的绘制成本约为单列列表的 **3 倍**，且逐项 hover 上浮在软渲染下每帧重绘整屏。

### 3. 低分辨率兼容（最低 800×600）

四档密度由 `html[data-size]` 的 CSS 变量统一驱动：

| 档 | 视口宽 | 任务栏 | 图标格 | 开始菜单 | 窗口最小 |
|---|---|---|---|---|---|
| xs | ≤900（含 800×600） | 38px | 74px | 292px | 300×180 |
| sm | ≤1280 | 42px | 86px | 320px | 340×200 |
| md | ≤1920（默认） | 48px | 92px | 344px | 360×220 |
| lg | ≥2560 | 56px | 104px | 400px | 360×220 |

**任务栏降级阶梯**（保证「全部可点」）：压缩间距 → 隐藏次要文字 → 快速启动折叠进 `»` → 任务按钮转图标-only → 最旧窗口进溢出菜单（**当前焦点永不折叠**）。任何被折叠的元素都能在溢出菜单中找到，不允许直接裁掉。

## 🧩 设置中心：模块化 DEB 架构

设置主程序 `ukui-control-center` **只是一个壳**（窗口 + 侧栏 + 搜索 + 调度），功能全部下沉为独立 DEB 包，**装几个显示几个**。

### 包规约

| 项 | 约定 |
|---|---|
| 包名 | `ukui-control-<id>_<ver>_<arch>.deb` |
| 可执行 | `/usr/bin/ukui-control-<id>`（独立进程入口） |
| 桌面入口 | `/usr/share/applications/ukui-control-<id>.desktop` |
| 模块注册 | `/usr/share/ukui-control-center/modules/<id>.desktop`（壳扫描此目录生成侧栏） |
| 配置存储 | GSettings `org.ukui.control-center.<id>` |

### 三种运行形态

1. **设置内打开** —— 壳扫描 modules 目录 → 侧栏生成 N 项 → 点击惰性构建
2. **单独运行** —— `ukui-control-power` 直接启动，只有该模块窗口，不加载壳
3. **启动器入口** —— 每个已安装模块在启动器「设置」分类中出现，可固定到任务栏/桌面

### 性能设计（打开速度第一）

- 首帧只同步构建「侧栏 + 当前一个模块页」，其余点击时才构建
- 构建过的页面 DOM 节点缓存复用，切回 0 重建
- 开关/选项片/滑块**行级更新**，不重建整页
- 搜索防抖 200ms + 截断 12 条
- 设置窗口**即使完整档也禁用毛玻璃**
- 头部徽章实时自证耗时：冷启动 / 首帧构建 / 缓存复用 / 搜索过滤

### 原型内置 10 个模块

`pkgmgr 模块管理(内置) · power 电源 · display 显示 · sound 声音 · wallpaper 壁纸与个性化 · network 网络 · account 用户账户 · datetime 时间与日期 · update 系统更新 · about 关于本机(内置)`

控制台可实时装卸：侧栏条目、启动器「设置」分类、独立窗口三处联动；卸载时该模块的独立窗口自动关闭。

## 🛠 后续落地方向

原型是 HTML/CSS/JS 实现，用于**验证设计与交互**。进入工程阶段时按 `DESIGN-SYSTEM.md` 第 9 章映射表迁移到 Qt/QML：

- 主题令牌 → QML `Theme.qml` 单例，配置持久化走 GSettings
- 毛玻璃 → `Qt5Compat.GraphicalEffects` / `MultiEffect`（仅完整档挂载）
- 窗口移动缩放 → 交给 `ukui-kwin` 的 `startSystemMove` / `startSystemResize`
- 模块发现 → `QDirIterator("/usr/share/ukui-control-center/modules", {"*.desktop"})`
- 页面惰性加载 → `Loader` + `Component` 复用
